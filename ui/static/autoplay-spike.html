Graph autoplay — Phase 0 spike

Gate for docs/projects/GRAPH_AUTOPLAY_PLAN.md. Answers the two questions that can each kill the feature. Open at http://127.0.0.1:5000/static/autoplay-spike.html so the origin matches the real app.

Spike A — does chained autoplay work without a gesture per track?

createController builds its own iframe, so we can't guarantee allow="autoplay" is delegated. Press play once. If tracks 2 and 3 start on their own, A passes. If either needs a click, autoplay chaining is unavailable and the feature degrades to a manual "next" button.

Spike B — can end-of-track be detected?

There is no ended event, and for a logged-out visitor duration reports the full track length while audio stops at ~30s — so position >= duration never fires. This page runs the plan's stall detector and reports which rule fired. Run it twice: once logged into Spotify in this browser, once in a private window.
