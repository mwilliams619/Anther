# Implemented archive

This directory contains historical plans, implementation notes, incident
reports, and design reviews for features that are now implemented or whose
work has been superseded. They are retained for rationale and traceability;
they are not current instructions or status reports.

Use the live documentation under `docs/`, especially `docs/ui.md`,
`docs/architecture.md`, `docs/tagging.md`, and `docs/artist-enrichment.md`,
for current behavior. The current work/status summary is
`docs/Jul_24_summary.md`.

Archived documents should not be edited to describe new behavior. Add current
changes to the live docs or the dated summary instead.
